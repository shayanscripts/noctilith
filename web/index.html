What am I looking at?

SPHEREx is a NASA telescope that photographs the whole sky in 102 infrared colours. Each square pixel is about 6 arcseconds across. Every frame here is one SPHEREx photo of the same patch, lined up north-up. Stars and galaxies stay put; asteroids and comets drift from frame to frame.

Every frame sees a slightly different colour (shown as λ, in microns), so some brightness changes are just colour. Compare mode pairs frames of similar colour for you.

What we did to the pictures

We never change the measurements with our own methods. Only NASA's own corrections touch the numbers:

  • Junk pixels: pixels NASA flags as cosmic-ray hits, dead, hot or cold are filled from their neighbours. Untick "Hide NASA-flagged junk pixels" to see them.
  • Background glow: sunlight scattered by dust in the solar system is removed using NASA's own model of it (the ZODI layer shipped with every image).

Everything else only changes how the pictures are shown, and each can be switched off:

  • One brightness setting for the whole flipbook, so nothing flickers unless the sky changed.
  • Colours: by default only the sharpest colours (0.75–2.4 µm). Choose "All colours" to see every frame.
  • Poor frames hidden: frames that only partly cover the spot, are much noisier, or glow along an edge. Tick "Show poor frames" to bring them back.
  • One image per visit: the middle value of each visit's frames (a few hours), which removes satellite trails. Untick it to see single frames; the spectrum, Compare and change detection always use the single frames.
  • Invert (off by default): dark stars on white, display only.
  • Red finder (Detail, off by default): the median of all long-colour frames (3.8–5 µm) minus the median of all sharp-colour frames, each divided by its own noise. Red = much brighter at long wavelengths than an ordinary star (cold brown dwarfs, dusty or very red objects); blue = bluer than average. NASA's own recipe from IRSA's Source Discovery notebook; display only.
  • Long colours (wide view, off by default): plays detectors D4–D6 (2.4–5 µm) instead of the sharp ones, for cold brown dwarfs. Each visit then gets its own brightness setting, because these frames are much noisier; brightness can't be compared between visits there.
  • Brightness vs time (click a spot): the same numbers as the spectrum, in date order, only in the colours the Colours menu shows, so a star's colour isn't mistaken for a change in brightness. It sums the star's light; flagged pixels are left out, and for a saturated star (R Dra) only the unflagged ring around its core is used, so it shows the shape of the change, not an absolute brightness.
  • Checkerboard = no data: that frame or visit didn't photograph this part of the sky. SPHEREx covers the sky in tilted tiles, so one picture often reaches only part of the box.
